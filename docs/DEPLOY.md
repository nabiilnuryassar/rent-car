# Deployment Checklist

Use this checklist after deploying code or refreshing production assets.

```bash
php artisan optimize:clear
php artisan route:cache
php artisan permission:cache-reset
npm run build
```

If Wayfinder route helpers are not generated by the Vite plugin in the target
environment, regenerate them before building assets:

```bash
php artisan wayfinder:generate --no-interaction
```

## Auth/session notes

- Set `APP_URL` to the canonical production host.
- Set `SESSION_DOMAIN` consistently for `www` vs non-`www` usage.
- Use `SESSION_SECURE_COOKIE=true` when serving over HTTPS.
- Reset Spatie permission cache after role or permission changes.
