## Catatan untuk Manual Book

1. Setiap UC ada minimal 1 screenshot dengan kondisi entry-state (form kosong / list awal). Kalau perlu screenshot interaksi (form ter-fill, after-submit), tinggal extend script di `tests/qa/run-e2e-walkthrough.mjs`.
2. Audit log (UC-23) belum ada UI list explicit — sekarang via service `AuditLogger` saja. Roadmap: bikin `/admin/audit-logs` page untuk Admin.
3. Customer order detail pakai numeric `id`, bukan `order_number` yang kelihatan di UI. Kalau mau pakai `order_number` sebagai route binding, ubah di `routes/web.php` (`/orders/{order:order_number}`).
4. Re-run: `node tests/qa/run-e2e-walkthrough.mjs` (membutuhkan app running di `localhost:8080`).
5. Re-render report: `node tests/qa/render-report.mjs` (script ini).
